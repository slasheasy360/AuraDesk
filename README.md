# AuraDesk

AuraDesk is an AI-powered productivity dashboard designed for solopreneurs and small businesses to manage all communications, leads, and workflows in one place.

## 🚀 Overview

AuraDesk combines messaging, CRM, automation, and AI into a single platform, allowing users to manage conversations across multiple channels efficiently.

## ✨ Core Features

- Smart Inbox (Facebook, Instagram, WhatsApp - where possible)
- AI-powered reply suggestions
- Lead management (CRM)
- Follow-up automation
- Invoice creation and tracking
- Reporting dashboard

## 🧱 Project Structure

/frontend → User interface (dashboard)
/backend → APIs, integrations, logic
/docs → Documentation and planning

## 🔗 Integrations (Planned)
